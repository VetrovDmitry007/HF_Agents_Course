# Умножение
- Для выполнения умножения используй скрипт: `scripts/multiplication.py`.
- Передай скрипту числа из запроса пользователя.
- Используй результат выполнения скрипта как итог вычисления.
- Для формирования итогового ответа обязательно прочитай дополнительную документацию:
`references/result_format.md`.
- Сформируй финальный ответ в соответствии с требованиями из дополнительной документации.
