# Формат результата умножения
Дополнительная документация навыка `multiplication`.

## Требования
- Используй результат, полученный после выполнения скрипта умножения.
- Не добавляй пояснения.
- Не добавляй промежуточные вычисления.

## Формат ответа
Верни результат строго в формате:
```text
ПРОИЗВЕДЕНИЕ: <результат>
```
Пример:
```text
ПРОИЗВЕДЕНИЕ: 42
```
