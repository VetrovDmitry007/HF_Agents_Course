# Формат результата деления
Дополнительная документация навыка `division`.

## Требования
- Используй результат, полученный после выполнения скрипта.
- Не добавляй пояснения.
- Не добавляй промежуточные вычисления.

## Формат ответа
Верни результат строго в формате:
```text
ЧАСТНОЕ: <результат>
```
Пример:
```text
ЧАСТНОЕ: 5
```

## Ошибка деления на ноль
Если делитель равен нулю, верни:
```text
ОШИБКА: деление на ноль невозможно
```
